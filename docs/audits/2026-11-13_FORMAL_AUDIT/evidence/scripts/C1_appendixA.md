## Appendix A. Evidence notes

Decompiled source checked: `Vermintide-2-Source-Code` HEAD 93dea911 "Added Version 6.13.0 10-13-26".

- N1. `-eac-untrusted` is what makes the Lua side modded: `foundation/scripts/util/application_parameter.lua:150-152` sets global `MODDED_REALM` from argv.
- N2. Retail strips argv -> `script_data`: `application_parameter.lua:154` copies parameters into `script_data` only when `DEDICATED_SERVER or BUILD ~= "release"`. But the parsed table `Development.application_parameter` (line 12, global) keeps EVERY `-name value` pair in retail, and `Application.argv()` itself stays callable. So the command line is a free inbound channel to mod Lua.
- N3. `Development.parameter(p)` in retail is `hardcoded_dev_params[p]` (`foundation/scripts/util/development_parameter.lua:3-29,55-57`); the table is reachable as `Development._hardcoded_dev_params`, so a mod can add keys (e.g. `skip_splash`, `auto_host_level`) and every later `Development.parameter(...)` call sees them.
- N4. Raw-argv flags honoured in retail (no BUILD guard): `-skip-splash` (`scripts/game_state/state_splash_screen.lua:113-125`), and `-skip-splash` / `-auto-host-level` / `-auto-join` / `-deus-auto-host` / `-vs-auto-search` / `-weave-name` set `StateTitleScreen._auto_start` (`scripts/game_state/state_title_screen.lua:56-62`), which skips "press any key" (`state_title_screen_main.lua:292`). `-attract-mode` / `-benchmark-mode` set `LAUNCH_MODE` (`scripts/boot_init.lua:52-68`).
- N5. Mods load during boot, before any game state: `scripts/boot.lua:391-415` (`init_mods` -> `loading_mods` -> `ready`). In `-benchmark-mode` mods are NOT loaded (`boot.lua:391`).
- N6. Retail scrubs `io`, `ffi`, `package.loadlib`, and trims `os` to clock/date/difftime/time/getenv: `scripts/boot_init.lua:223-250`.
- N7. Modded realm = read-only backend + achievements off: `scripts/settings/game_settings_development.lua:49-52`.
- N8.
