# Chest of Trials Crash Report (2026-05-23)

## Summary
Host-side crash when opening a Chest of Trials at 02:09:30 UTC. The crash prevented the boon selection UI from appearing.

## Crash Metadata
- **Dump filename**: `crash_dump-2026-05-24-01.42.07-8243cbfe-a093-41ae-8a61-3f57e1b922a9.dmp`
- **Timestamp**: 2026-05-23 21:42:07 UTC
- **Console log**: `console-2026-05-24-01.42.07-8243cbfe-a093-41ae-8a61-3f57e1b922a9.log`

## Root Cause: Scope Mismatch on DORMANT_BOON_RARITY

**Lua error (line 983):**
```
scripts/mods/chaos_wastes_tweaker/chaos_wastes_tweaker.lua:983: attempt to index global 'DORMANT_BOON_RARITY' (a nil value)
```

**Root cause (1 sentence):** The `generate_random_power_ups` hook (line 880) references a **global** `DORMANT_BOON_RARITY` upvalue that was never assigned because line 4448 defines it as a **local variable** instead.

## Call Stack (top 5 frames)
```
1. chaos_wastes_tweaker.lua:983: in function _should_strip
2. chaos_wastes_tweaker.lua:999: in function hook_chain

```

The crash fires when `deus_chest_extension` calls `generate_random_power_ups` to roll boons for the chest display, which invokes the mod's hook closure, which attempts to index the nil global.

## Dormant Boon Connection: YES

The error is **entirely in the dormant boon gating logic**. Line 983 is:
```lua
if DORMANT_BOON_RARITY[name] and not effective_setting("activate_dormant_" .. name) then
```

This gate was added to filter out dormant boons (squats, deus_larger_clip, deus_throw_speed_increase, deus_ammo_pickup_give_allies_ammo, deus_coin_pickup_regen, deus_large_ammo_pickup_infinite_ammo, deus_timed_block_free_shot, deus_transmute_into_coins, explosive_pushes_on_damage_taken) when their toggles are OFF. Since `DORMANT_BOON_RARITY` is nil, the indexing fails immediately.

## Skulls Event Boons: Not Involved

The Skulls event boons are mutated via `_set_skulls_mutators_active()` (line 4839-4866) which reads `DeusPowerUps.event` tables, not `DORMANT_BOON_RARITY`. Skulls boon involvement is ruled out.

## Other Errors in Log

None. The only error surface in the post-crash session review is this single Lua error + crash.

## Regression Test Recommendation

After fix, add a regression test that:
1. Registers the `generate_random_power_ups` hook early (line 880)
2. Calls `mod:command("ct_regression_test")` to verify all dormant boon tables are accessible from the hook closure
3. Opens a Chest of Trials and verifies the boon selection UI renders without crashing

The fix is to change line 4448 from `local DORMANT_BOON_RARITY = {` to `_G.DORMANT_BOON_RARITY = {` (or assign to the local and explicitly make it global after definition).
