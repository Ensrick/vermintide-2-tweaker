## Shared causes

- **A. Both Weapon Tweaker streams loaded (12 rows).** `sweep-dev.json` loads public wt (inventory stream `single`) and wt_dev (stream `dev`); `New-SmokePlan.ps1` takes both (`tools/mod-inventory.psd1:44-57`).
  - With both loaded, wt_dev's `/wt_regression_test` is refused as a duplicate name (`console.log:2747`), so wt_dev's suite never runs in any of the three runs. Both streams write the same game data (wt rows 341, 282, 597).
  - wt_dev's history catalog is rejected because wt registered the same `wt_hist_*` rows first (`console.log:2735`). Every CWV construction proof binds both runtimes, so 7 CWV rows fail, plus 2 knock-on rows.
  - In run `-165827` (wt 0.12.350 with the sibling guard), the guard disabled public wt (`[wt:SIBLING] wt and wt_dev are both enabled; disabling public wt`) after the collision had already happened, so no WT suite ran at all.
  - The collision itself is a WT defect for any player with both streams enabled: the sibling guard yields only from `mod.update`.
- **B. Modded Progression's Fresh route is active in the owner's profile (5 rows).** `starting_state = "fresh"` redirects the items interface to the Fresh profile (`modded_progression/scripts/mods/modded_progression/_mp_fresh_profile_runtime.lua:523-525, 555-557`), which hides every MoreItemsLibrary row: the CWV Blacksmith seeds and the WOC relic. Players on Fresh likely hit the same gap. The mp changelog lists this part of the Fresh route as unfinished.
- **C. Enemy Tweaker registers its custom breeds before the network config exists (7 rows).**
  - Both breeds register once, inside `mod:dofile` at mod load (`enemy_tweaker/scripts/mods/enemy_tweaker/enemy_tweaker.lua:82-83`). That is before vanilla creates `NetworkConstants` (`Vermintide-2-Source-Code/scripts/game_state/state_loading_restart_network.lua:161`).
  - The capacity probe fails with "Network config not loaded" (`console.log:2847-2850`). The registrar fails closed (`_et_custom_breed_registrar.lua:509-523, 956-957`) and never retries.
  - The capacity was there 43 s before the suite ran (`console.log:6335-6338`).
